# UTS Graf Sains Data: Rekomendasi RetailRocket dengan Neo4j

Nama: Grace Pinkkan Ladyna | NIM: 24031554137 | Kelas: 2024B

## Isi
- `uts-gsd.ipynb`: notebook jawaban (bagian 1 dan soal UTS 2.1, 2.2)
- `data/events_p1.csv`: data periode P1 (1 Juni - 15 Agustus 2015)
- `data/events_p2.csv`: data periode P2 (16 Agustus - 18 September 2015)
- `requirements.txt`: dependensi Python

## Cara menjalankan
1. Install paket: `pip install -r requirements.txt`
2. Jalankan Neo4j (versi 5 ke atas), lalu sesuaikan `URI` dan `AUTH` di sel setup.
3. Dataset penuh `events.csv` (RetailRocket, Roman Zykov) diunduh dari Kaggle dan ditaruh di folder `data/`.
